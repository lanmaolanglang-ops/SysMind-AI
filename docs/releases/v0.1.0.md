# SysMind AI v0.1.0 release notes

Release status: pending production code signing and final release validation.

v0.1.0 is the first Windows x64 release candidate for SysMind AI, a local-first diagnostic desktop
application. It implements the PRD through Phase 6.

## Highlights

- Read-only system snapshots and bounded Windows event-log analysis.
- Evidence-backed natural-language diagnosis with redacted JSON and Markdown export.
- A versioned, policy-gated agent tool registry that cannot execute model-authored commands.
- Explicit, parameter-bound confirmation for narrowly scoped current-user startup and process actions.
- A frozen FastAPI backend owned by the Tauri desktop process and protected by a random loopback port,
  environment-only session token, Origin checks, and Windows Job Object lifecycle management.
- Per-user NSIS packaging, single-instance behavior, preserved local data on upgrades and silent
  uninstall, and explicit data deletion during interactive uninstall.
- Signature-verified in-app update support with an explicit install-and-restart action.

## Security and privacy

- No mandatory analytics or crash telemetry.
- Diagnostic and audit history remains local unless the user explicitly exports it.
- The AI model cannot directly call Win32, Shell, PowerShell, CMD, or arbitrary commands.
- Formal artifacts must carry valid timestamped Authenticode signatures and Tauri updater signatures.
- Vulnerabilities can be reported through the repository's private security-advisory channel.

## Validation completed

- Backend Ruff, strict mypy, and 90 pytest tests passed; four state-changing tests remain gated to a
  disposable Windows environment.
- Frontend ESLint, TypeScript, 25 Vitest tests, and production build passed.
- Rust tests, frozen-backend process checks, packaged desktop lifecycle checks, and GitHub-hosted
  unsigned NSIS install/launch/uninstall-preserve validation passed.

## Remaining release gates

The production v0.1.0 release will not be published until a trusted Windows code-signing certificate
is configured, signed artifacts pass Authenticode verification and antivirus review, the signed
updater rejection path is tested, and the manual Windows 10/11 release matrix is complete. Database
downgrades are unsupported; recovery uses a forward fix.
