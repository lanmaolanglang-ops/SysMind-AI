# 网络案例：无法联网

- 验证日期：2026-08-23
- 验证方式：受控证据夹具 + Windows 11 x64 有界网络工具冒烟
- 用户描述：无法联网
- 设备环境：普通用户权限；网络检查仅访问应用固定目标，代理读取为只读
- 实际问题：夹具中存在默认路由，但 DNS 解析无结果，固定 ICMP 目标丢包率 100%
- SysMind 诊断结果：选择代理与分层网络检查；报告指出 DNS 检查失败和连通性受限，同时明确 ICMP 不能单独证明网络故障
- 人工评价：通过。没有把代理启用或 ICMP 无响应直接写成根因，关键网络证据与时间可见
- 尚待复核：企业代理、禁用 ICMP 和受管 DNS 环境中的提示可读性
