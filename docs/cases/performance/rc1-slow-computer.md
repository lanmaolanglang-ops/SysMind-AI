# 性能案例：电脑最近很卡

- 验证日期：2026-08-23
- 验证方式：受控证据夹具 + Windows 11 x64 真实只读适配器冒烟
- 用户描述：电脑最近很卡
- 设备环境：普通用户权限；CPU、内存、磁盘和进程只读工具可用
- 实际问题：夹具中 CPU 使用率 92%，系统盘使用率 95%，并存在高占用进程
- SysMind 诊断结果：选择性能检查；报告优先指出 CPU 高负载和磁盘空间压力，并把结论关联到工具、检查时间和关键百分比
- 人工评价：通过。结论与已知输入一致，工具失败时仍可生成降权的部分报告；建议不包含自动终止进程或删除文件
- 尚待复核：不同硬件上的瞬时采样代表性，以及间歇性卡顿在问题未复现时的信息不足提示
